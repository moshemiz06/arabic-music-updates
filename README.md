# Arabic Music Test updates

Download the **arm64-v8a APK** from [the latest release](https://github.com/moshemiz06/arabic-music-updates/releases/latest) on your Pixel. Install over the existing Arabic Music Test app to keep your playlists, downloads and settings.

This download channel works over mobile data or any Wi-Fi. After the bootstrap update, the app checks for new releases automatically and offers verified in-app downloads. Android asks before installing. Local only pauses checks and downloads.

Each release includes matching GPL-3.0 app source and build instructions in its source archive, along with APK checksums and update metadata. Arabic Music Test is based on [Koda](https://github.com/Ivorisnoob/Koda). Original upstream notices are retained in the source archive.

The development repository and its history remain private. This channel contains no personal music collection, playlist files, account credentials or signing keys.
